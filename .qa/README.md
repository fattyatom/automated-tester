# .qa — working directory

Generated by `npm run analyze` and the test run (git-ignored except this file and `overlay/`):

- `model.json` — what the tool inferred from the vault (pages, flows, fields, auth, ACs)
- `plan.json` — every test the suites will generate
- `coverage.md` — knowledge gaps and risk hotspots
- `discovered/` — live crawl results per persona (used by `analyze` to diff docs vs reality)
- `test-strategy.md` — written by the `qa-cartographer` agent

`overlay/` holds agent-written notes that merge over the vault by note name (frontmatter keys
override, body is appended). It lets agents add routes, field rules or normalized ACs without
touching the team's real vault. Review and promote them into the vault when they're right.
